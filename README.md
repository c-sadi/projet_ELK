# projet_ELK
Projet réalisé en équipe de 3 dans le cadre de notre cours sur la stack ELK. On part d'un dataset de films récupéré depuis Kaggle, on nettoie et on indexe les données dans Elasticsearch via Logstash, et on visualise dans un dashboard Kibana et un petit moteur de recherche. Tout tourne en local avec Docker Compose.
